# Delta Plus PWA

المشروع الحالي Next.js 16 App Router وReact، مع API منفصل. دعم PWA مضاف إلى التخطيط العام دون تغيير تصميم الصفحات أو قاعدة البيانات أو الصلاحيات.

## الهوية والملفات

- الاسم `Delta Plus` والاسم المختصر `Delta+`، باللغة العربية واتجاه RTL.
- `public/manifest.webmanifest`: هوية ثابتة `/`، ونطاق `/`، وصفحة بداية `/`، ووضع `standalone`، ولون `#0d182e`.
- `app/layout.jsx`: يربط Manifest والأيقونات ووسوم Apple وtheme-color بجميع الصفحات.
- `public/brand/delta-plus-pwa-source.jpeg`: نسخة من الشعار المرفق، دون إعادة رسم أو قص.
- `public/favicon.ico`: أحجام 16 و32 و48 و64 داخل الملف نفسه.
- `public/favicon-32x32.png`، `apple-touch-icon.png` (180)، `icon-192.png`، `icon-512.png`، `maskable-icon-192.png`، `maskable-icon-512.png`.
- أيقونات Maskable تحافظ على الكتابة وعلامة + داخل دائرة الأمان؛ خلفية الصورة الأصلية تمتد إلى الحواف.

إعادة إنشاء الأيقونات من الشعار المحفوظ، باستخدام مكتبة sharp الموجودة مسبقًا:

```powershell
npm.cmd run icons:generate --workspace apps/web
```

## التثبيت

افتح النظام عبر HTTPS بشهادة موثوقة وعلى نفس اسم النطاق المستخدم دائمًا:

1. Windows: في Chrome أو Edge، اختر تثبيت التطبيق من شريط العنوان أو قائمة المتصفح.
2. Android: في Chrome، اختر تثبيت التطبيق أو الإضافة إلى الشاشة الرئيسية، حسب إصدار المتصفح.
3. iPhone/iPad: في Safari، اختر مشاركة ثم إضافة إلى الشاشة الرئيسية. فعّل «فتح كتطبيق ويب» إذا ظهر الخيار.

ظهور زر التثبيت وموضعه يعتمدان على المتصفح وإصداره. لا يتطلب التثبيت طلب صلاحية الإشعارات. يعمل التطبيق المثبت في وضع مستقل بالاسم والشعار المحددين.

## الأمان والتحديث

`public/sw-notifications.js` يحتفظ بمسار ونطاق عامل الإشعارات الموجودين، حفاظًا على اشتراكات Push الحالية. التسجيل مشترك بين `components/PwaRegistration.jsx` و`lib/notifications.js` عبر `lib/registerServiceWorker.mjs`.

- لا يستخدم العامل Cache Storage أو IndexedDB، ولا يخزّن صفحات الدخول أو بيانات المستخدمين.
- تنقلات الصفحات تعتمد على الشبكة مع `cache: no-store`؛ عند انقطاع الاتصال تُعرض رسالة عربية ثابتة دون بيانات.
- لا يعترض API أو uploads أو موارد Next.js أو طلبات البيانات/RSC أو POST أو النطاقات الأخرى.
- لا يوفر النظام وضع تحرير أو حفظ بيانات دون اتصال؛ وظائفه المعتادة تحتاج الخادم.
- يجري فحص تحديث العامل عند فتح التطبيق وعودة الاتصال والتركيز وبصفة دورية، دون فرض إعادة تحميل تفقد المستخدم بيانات نموذج مفتوح.
- لا يُخزّن ملف العامل مؤقتًا، ويُعاد التحقق من Manifest والأيقونات. تبقى ملفات Next.js ذات الأسماء المرمّزة تحت سياسة التخزين المعتادة.
- بعد نشر نسخة جديدة، إعادة فتح التطبيق/تحديث الصفحة تجلب النسخة الجديدة من الخادم دون حذف الاختصار أو إعادة تثبيته. قد يؤجل نظام التشغيل تحديث اسم/أيقونة الاختصار وفق سياسته الخاصة.

## النشر عبر HTTPS

`localhost` استثناء للتطوير فقط؛ فتح عنوان LAN عبر HTTP لا يحقق شروط التشغيل الآمن. وفّر HTTPS بشهادة موثوقة للواجهة، واحرص على أن يكون اتصال API أيضًا HTTPS أو عبر مسار من نفس النطاق، لتجنب mixed content. اضبط `NEXT_PUBLIC_API_URL` وفق بنية النشر الحالية ثم ابنِ المشروع. لا تُنشر شهادة الاختبار المحلية أو مفتاحها.

يجب ألا يحوّل reverse proxy مسارات Manifest والأيقونات والعامل إلى صفحة الدخول، وأن يحافظ على MIME وCache-Control وService-Worker-Allowed المحددة في `next.config.js`. لا تغيّر هذه الإعدادات سياسة حماية بيانات API.

## التحقق

```powershell
npm.cmd run check:pwa --workspace apps/web
npm.cmd run check:pwa --workspace apps/web -- https://your-domain.example
npm.cmd run build --workspace apps/web
```

الفحص يختبر Manifest وأحجام PNG ومحتوى ICO ودائرة أمان Maskable، وتجاوز API/auth/data، ورسالة انقطاع الاتصال واستمرار معالج Push. مع رابط الخادم يفحص جميع مسارات الأيقونات وMIME وسياسة تحديث العامل والوسوم المشتركة في ثلاث صفحات.

يمكن استخدام `NEXT_DIST_DIR` لبناء نسخة تحقق مستقلة دون الكتابة فوق مخرجات خادم التطوير الجاري.

تم التحقق من البناء الإنتاجي ومسارات HTTPS محلية. اختبار HTTPS المحلي يستخدم شهادة مؤقتة خاصة بالاختبار ولا يثبت جاهزية شهادة نطاق الإنتاج. يجب استكمال اختبار الإضافة للشاشة الرئيسية على iPhone/Safari فعلي، إذ لا يتوفر على جهاز Windows هذا.

نتائج التحقق الآلي على Windows:

| الفحص | النتيجة |
| --- | --- |
| بناء Next.js الإنتاجي | ناجح، 36 صفحة ثابتة مع المسارات الديناميكية الحالية |
| Chrome 156.0.8078.49 عبر HTTPS محلي | Manifest دون أخطاء، وقائمة أخطاء قابلية التثبيت فارغة |
| Edge 156.0.4314.50 عبر HTTPS محلي | Manifest دون أخطاء، وقائمة أخطاء قابلية التثبيت فارغة |
| Chrome وEdge: العامل والتحديث وانقطاع الشبكة | ناجح؛ نطاق العامل `/`، وفحص تحديثه ورسالة الانقطاع يعملان |
| Chrome وEdge: التخزين والصلاحيات | Cache Storage فارغ، ولم يطلب الاختبار إذن الإشعارات |
| مسارات الأيقونات وManifest ووسوم الصفحات عبر HTTPS | ناجح، مع التحقق من الأحجام وMIME وترويسات العامل |

استُخدمت جلسات متصفح معزولة بشهادة محلية مؤقتة مقبولة داخل جلسة الاختبار فقط؛ لم تُثبّت شهادات في مخزن النظام أو تطبيقات في حساب المستخدم. فحص قابلية التثبيت لا يغني عن تجربة التثبيت الفعلية على أجهزة Android وiPhone المستهدفة.
